# PoCまとめ

## 目的

Oracle 会計システムをイメージした DB をPostgreSQLへ移植し、
移植方法の検証、およびその実施と、データ取得と作成処理に係る性能比較を行った。
また、事前にデータを集約して作成することの有効性を検証した。

---

## 成果

- 全テーブル移植完了
- 全Procedure移植完了
- SQL移植完了
- Oracleとの結果一致

---

## 性能評価

- Oracleより高速なSQLあり
- PostgreSQLで遅いSQLも確認
- 実行計画差異を確認
  (ワークロード特性によって作成される実行計画が異なることを確認)

---

## 学んだこと

- Oracle固有機能の代替実装が必要。
- PostgreSQL において、1トランザクション=1コミットの原則を意識する必要がある。
- 実行計画を見ながらチューニングすることが重要。
- 両DB共に、事前にデータを集約したことへの有効性を確認できた。
- Oracle 側では、明細データを事前作成することの有効性は確認できなかった反面、
  PostgreSQL 側では、単一のインデックススキャンで完了していたこともあり、有効性を確認できた。
- OracleとPostgreSQLでは同様のSQLでも異なる実行計画が選択される。
